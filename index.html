🐧 How to Boot Linux on PS5

  1. Format an external USB 3.0 / SSD drive with a FAT32/exFAT boot partition and an ext4 Linux root filesystem.
  2. Connect the USB drive to the rear USB port of the PS5.
  3. Copy your Linux loader payload (e.g., ps5-kexec.elf) into the payloads/ folder on your host computer.
  4. Run the Jailbreak from the Exploit Console tab until the ELF loader is active on port 9021.
  5. Switch to the Payloads tab, locate your Linux loader, and click Send to PS5.
  6. The PS5 kernel will handover execution to the Linux bootloader and start kernel initialization.
